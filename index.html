4 Cómo trabajar en equipo (guía rápida)

Antes de empezar cualquier tarea:

  1. Clona el repo y crea tu entorno virtual: 
    git clone <url-del-repo>
cd labor-income-credit-quality
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
  2. Antes de tocar código, actualiza tu rama local: 
    git checkout main
git pull
  3. Crea una rama con tu nombre/tarea (no trabajar directo sobre main): 
    git checkout -b tu-nombre/tarea-corta
# ej: git checkout -b camila/informalidad-geiheiss
  4. Corre los scripts existentes para entender el pipeline antes de agregar algo nuevo: 
    python src/procesar_banrep_sdmx.py
python src/procesar_sfc_calidad_cartera.py
python src/procesar_geih.py
python src/consolidar_panel.py
  5. Haz commits pequeños y frecuentes con mensajes claros, y sube tu rama: 
    git add .
git commit -m "Agrega informalidad desde anexo GEIHEISS"
git push -u origin tu-nombre/tarea-corta
  6. Abre un Pull Request hacia main para que alguien más revise antes de mezclar (evita pisar el trabajo de otros y detecta errores en los datos a tiempo).
  7. Actualiza docs/fuentes_de_datos.md cada vez que agregues o cambies una fuente de datos (fecha de corte, fecha de descarga, notas) — es el registro de trazabilidad del equipo.
Regla de oro con los datos: nunca edites a mano los archivos de data/raw/. Todo lo "crudo" se queda intacto; toda limpieza/transformación va en un script de src/ que escribe su salida en data/processed/. Así el trabajo es 100% reproducible y auditable por cualquiera del equipo.

5 Resultados clave

📉 Desempleo vs. ingreso real

El desempleo agregado sí es significativo en el modelo de brecha por tramo (p = ,041), pero el canal que discrimina entre deudores de bajos y altos ingresos dentro del mismo producto es la erosión del ingreso laboral real, no la pérdida del empleo.

💳 La brecha se concentra en tarjeta de crédito

El mismo choque de ingreso real mueve el ICV en consumo sin garantía (−0,235) y en descuento de nómina (−0,024, un orden de magnitud menor) pero es estadísticamente nulo en crédito con garantía real, microcrédito y comercial.

🏛️ Tres resultados nulos reportados como tales

La moderación por tasa de política no es significativa, el efecto agregado del panel completo es débil, y el ingreso rezagado seis meses no tiene efecto — el canal es contemporáneo, no de rezago largo.

🧮 5 especificaciones + 7 robustez
