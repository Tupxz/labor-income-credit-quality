# Notebooks

Convención de nombres: `NN_descripcion.ipynb` (ej. `01_exploracion_datos.ipynb`,
`02_modelo_panel.ipynb`, `03_robustez_var.ipynb`). Mantener los notebooks livianos: la lógica
reutilizable (ingesta, transformación, modelo, gráficos) va en `src/`, y los notebooks solo la
invocan para explorar/documentar resultados.
